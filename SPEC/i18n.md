## 責務
- 文字列 ID を locale ごとの実体文字列へ解決する規約を定義する。
- text API で VM に文字列を直接持ち込まない方針を定義する。

## 依存
- 文字列テーブルは [SPEC/resource.md](resource.md) に依存する。
- 表示 API は [SPEC/hostapi.md](hostapi.md) に依存する。

■ 1. Text Resource層（データ）
WMLResource/i18n
├─ string_table
├─ locale_table
├─ font_map
中身イメージ
string_id = 1001

ja: "こんにちは"
en: "Hello"
fr: "Bonjour"

👉 VMからは

text.get(1001)
■ 2. Runtime解決層（Host側）
WMLHost/i18n
├─ current_locale
├─ fallback_chain
├─ string_resolver

処理：

string_id → locale → string

例：

1001 + ja → "こんにちは"

fallback：

ja → en → default
